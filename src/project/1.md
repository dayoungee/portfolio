# 📌 Summary

### **Judy go Home은 Unity와 C# 기반으로 개발한 2D 플랫포머 게임입니다.**  
### 플레이어는 몬스터와 장애물을 피해 목적지에 도착해야 하며, 아이템 획득과 몬스터 피격을 통해 점수를 얻을 수 있습니다. 일정 조건을 만족하면 일반 클리어와 별도로 Perfect Clear 엔딩을 확인할 수 있도록 구성했습니다.

### 학부 시절 Unity 과목 실습을 기반으로 시작한 프로젝트이며, 이후 소프트웨어 학술제 출품을 위해 게임성을 확장했습니다.  
### 초기에는 플레이어 이동 중심의 단순 구조였지만, 아이템, 장애물, 몬스터 AI, 점수 시스템, 엔딩 분기 등을 추가하여 하나의 완성된 스테이지로 구성했습니다.

### Android와 PC 환경에서 플레이할 수 있도록 개발했으며, Unity Asset Store의 무료 에셋인 Sunnyland를 활용했습니다.  
### 게임은 타이틀, 스테이지, 게임 오버, 게임 클리어, 퍼펙트 게임 클리어 총 5개의 Scene으로 구성되어 있습니다.

### 해당 프로젝트로 협업 스터디 발표 우수상과 소프트웨어 학술제 공모전 2등을 수상했습니다.

<br>

# 주요 기능

- #### 플레이어 이동 및 점프 기능
- #### 아이템 획득 시 Score 증가
- #### 몬스터 접촉 시 Life 감소
- #### 지정 경로 이동 몬스터 구현
- #### 플레이어 감지 범위 진입 시 추적하는 AI 몬스터 구현
- #### 몬스터 피격 처리 기능
- #### 박스 이동을 활용한 장애물 통과 기능
- #### Score 4,000점 이상, Life 3개 유지 시 Perfect Clear 엔딩 분기
- #### Android 및 PC 환경 지원
