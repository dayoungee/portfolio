# 📌 Summary

### **Tetris는 C++/MFC 기반으로 개발한 다이얼로그 기반 테트리스 게임입니다.**
### MFC 애플리케이션 구조와 Windows 기반 클라이언트 프로그램 개발 방식에 익숙해지기 위해 진행한 개인 프로젝트입니다.

### 기본적인 테트리스 게임 로직을 구현한 뒤, 레지스트리를 활용한 설정 저장, MySQL 기반 로그인/회원가입, TCP 통신 기반 1:1 채팅 기능을 추가했습니다.
### 이를 통해 단순 게임 구현을 넘어 클라이언트 프로그램에서 로컬 설정 관리, DB 연동, 네트워크 통신 기능을 함께 다뤄볼 수 있었습니다.

### Timer 기반으로 블록 이동과 화면 갱신을 처리했으며, 사용자 설정값과 계정 정보를 외부 저장소와 연동하는 구조를 경험했습니다.
### 이 프로젝트를 통해 이후 MFC 기반 실무 프로젝트를 수행하기 위한 클라이언트 개발 기초와 통신 흐름을 익힐 수 있었습니다.

<br>

# 주요 기능

- #### Timer 기반 블록 좌표 이동 및 화면 갱신
- #### 테트리스 블록 회전, 이동, 라인 제거 로직 구현
- #### 레지스트리를 활용한 배경색 설정 저장
- #### 배경음악 재생 및 정지 기능
- #### MySQL 기반 로그인 및 회원가입 기능
- #### TCP 통신 기반 1:1 채팅 기능
