# Stack Overflow Clone Coding

**2023.06.14 ~ 2023.06.26 · 7인 팀 프로젝트**

Q&A 커뮤니티의 핵심 기능을 구현한 프로젝트입니다. 팀장을 맡아 백엔드 일정을 관리하고 Question 도메인 API와 개발 환경 구성을 담당했습니다.

## 담당

- 질문 작성, 수정, 삭제, 조회 및 페이지네이션 API
- Spring Security와 JWT 기반 인증 처리
- AWS EC2와 Jenkins 기반 테스트 서버 및 자동 배포 구성
- Spring Rest Docs와 Swagger UI 기반 API 문서화

## 기술

`Java` `Spring Boot` `JPA` `MySQL` `JWT` `AWS` `Jenkins`
