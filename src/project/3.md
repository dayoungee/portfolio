# 📌Summary

### Portfolio 정적 웹 어플리케이션은 포트폴리오 용으로 개발했습니다. 미적 감각이 뛰어나지 않아 기존에 있던 템플릿을 따와 헤더와 모달을 추가하고, 디자인을 수정했습니다.

### Client 자체적으로 실행되고 있기 때문에 Context Api로 Mock 데이터를 공유하고 있습니다. 그렇기 때문에 server가 붙지 않았다는 점이 아쉬웠습니다. 추후에 Spring 기반으로 서버를 개발해 해당 웹 어플리케이션이 동적으로 데이터를 받아오게끔 해볼 예정입니다.

### 해당 포트폴리오는 netlify로 배포되어 있습니다. netlify와 Github가 연동되어 자동 배포를 경험해볼 수 있었습니다.

<br>

### 주요기능

- #### 프로젝트 모달 세부 페이지 추가
- #### 헤더 기능 추가(클릭 시 해당 섹션으로 이동)
- #### 메인 페이지 배경 디자인 추가
- #### 반응형 웹페이지
- #### 프로젝트 확인, 이력서 확인 버튼
