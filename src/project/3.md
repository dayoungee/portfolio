# 📌 Summary

### **Stack Overflow Clone Coding은 Q&A 커뮤니티의 핵심 기능을 구현한 팀 프로젝트입니다.**  
### 프론트엔드 4명, 백엔드 3명으로 구성된 팀에서 팀장을 맡아 일정 관리와 역할 분담, 프론트엔드와의 API 협업을 함께 진행했습니다.

### 백엔드에서는 User, Question, Answer 도메인으로 역할을 나누어 개발했으며, 저는 Question 도메인의 API 개발을 담당했습니다.  
### 질문 작성, 수정, 삭제, 상세 조회, 목록 조회, 페이지네이션, 정렬 기능을 구현하고, 인증이 필요한 API는 Spring Security와 JWT 기반으로 처리했습니다.

### 프로젝트 초기 단계에서 AWS EC2 기반 테스트 서버와 Jenkins CI/CD 환경을 구축했습니다.  
### 공용 GitHub Repository 환경에서 GitHub Actions 사용이 어려운 제약이 있어 Jenkins를 적용했고, 코드 변경 후 테스트 서버에 자동 배포되는 흐름을 구성하여 팀원들이 동일한 환경에서 기능을 확인할 수 있도록 했습니다.

### API 문서화는 Spring Rest Docs와 Swagger UI를 함께 활용했습니다.  
### 테스트 코드를 기반으로 API 문서를 생성하면서도 프론트엔드에서 Swagger UI를 통해 직접 API를 테스트할 수 있도록 OpenAPI3 Spec 변환 구조를 적용했습니다.

# 🔍 Contribution

### 테스트 서버 및 CI/CD 환경 구축

프로젝트 시작 단계에서 AWS EC2에 테스트 서버를 구성하고 Jenkins 기반 CI/CD 환경을 구축했습니다.  
공용 Repository 환경에서도 자동 배포가 가능하도록 Jenkins Job을 구성하여, 백엔드 기능 변경 사항을 테스트 서버에 빠르게 반영할 수 있도록 했습니다.

<br>

### API 문서화 환경 구성

프론트엔드와의 협업을 위해 Spring Rest Docs와 Swagger UI를 함께 사용하는 문서화 구조를 구성했습니다.  
Spring Rest Docs 테스트 결과를 OpenAPI3 Spec으로 변환하고, 이를 Swagger UI로 제공하여 문서의 신뢰성과 테스트 편의성을 함께 확보했습니다.

<br>

### 인증 API 테스트 흐름 개선

Spring Security 적용 이후 인증이 필요한 API의 테스트 코드와 Swagger 테스트 과정에서 인증 처리가 필요했습니다.  
테스트용 JWT를 발급하고 Authorization Header에 포함하는 방식으로 테스트 코드를 구성했으며, Swagger UI의 Authorize 기능을 활성화하여 인증 API도 직접 테스트할 수 있도록 개선했습니다.

<br>

# ✅ Result

### 팀장으로서 백엔드 개발 일정과 협업 흐름을 관리하며, Question 도메인 API 개발과 배포 환경 구성을 담당했습니다.  
또한 EC2, Jenkins, Docker 기반 테스트 서버를 구성하고, Spring Rest Docs와 Swagger UI를 연동한 API 문서화 환경을 구축하여 프론트엔드와의 협업 효율을 높였습니다.

### 이 프로젝트를 통해 단순 기능 구현뿐 아니라 테스트 서버 운영, CI/CD 구성, API 문서화, 인증 API 테스트 흐름까지 백엔드 개발 과정 전반을 경험했습니다.
