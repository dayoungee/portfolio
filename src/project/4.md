# PliP

**2023.06.29 ~ 2023.07.26 · 6인 팀 프로젝트**

여행 일정과 일지를 관리하는 웹 서비스입니다. 회원 도메인을 담당해 인증과 사용자 관련 기능을 개발했습니다.

## 담당

- 회원가입, 로그인, 회원 정보 관리 API
- JWT 인증과 카카오·네이버 OAuth2 로그인
- Redis 기반 Refresh Token, 로그아웃 블랙리스트와 이메일 인증 관리
- Batch Size 조정을 통한 조회 쿼리 감소

## 기술

`Java` `Spring Boot` `Spring Security` `JPA` `MySQL` `Redis` `AWS`
