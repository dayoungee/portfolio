# 📌 Summary

### **PliP은 지도 기반으로 여행 일정을 계획하고, 여행 후 일지를 작성할 수 있는 웹 서비스입니다.**  
### 프론트엔드 3명, 백엔드 3명으로 구성된 팀에서 진행했으며, 백엔드는 일정, 일지, 회원 도메인으로 역할을 나누어 개발했습니다.

### 저는 회원 도메인을 담당하여 회원가입, 로그인, 소셜 로그인, 회원 정보 관리, 이메일 인증, 토큰 재발급, 로그아웃 처리 등을 개발했습니다.  
### Spring Security와 JWT 기반 인증 구조를 적용하고, OAuth2.0을 활용해 카카오/네이버 소셜 로그인을 구현했습니다.

### 또한 Redis를 활용해 Refresh Token, 로그아웃 토큰 블랙리스트, 이메일 인증코드를 관리했습니다.  
### 토큰 만료 시간과 인증코드 유효 시간을 Redis TTL로 관리하여 인증 관련 데이터를 효율적으로 처리할 수 있도록 구성했습니다.

# 🔍 Contribution

### 회원 도메인 API 개발

회원가입, 로그인, 로그아웃, 회원 탈퇴, 회원 정보 수정, 마이페이지 조회 등 회원 관련 API를 개발했습니다.  
일반 로그인뿐 아니라 카카오/네이버 OAuth2 로그인을 함께 지원하도록 구성하고, 소셜 로그인 이후 자체 JWT를 발급하는 흐름을 구현했습니다.

<br>

### JWT 인증 및 Redis 기반 토큰 관리

Access Token은 클라이언트 메모리에서 관리하고, Refresh Token은 HttpOnly 및 Secure 옵션을 적용한 Cookie로 전달하도록 정책을 구성했습니다.  
로그아웃 시 Access Token을 Redis 블랙리스트에 저장하고, 토큰의 남은 유효 시간만큼 TTL을 설정하여 만료 데이터를 자동 정리하도록 구현했습니다.

<br>

### 이메일 인증 및 알림 기능 개발

회원가입, 비밀번호 재설정, 일정 생성 알림에 필요한 이메일 전송 기능을 구현했습니다.  
JavaMailSender를 활용해 메일을 발송하고, 이메일 인증코드는 Redis에 저장하여 유효 시간을 관리했습니다. 메일 발송 과정은 비동기로 처리하여 API 응답 지연을 줄였습니다.

<br>

### N+1 문제 개선 및 로깅 적용

일부 조회 API에서 발생한 N+1 문제를 확인하고, Fetch 전략과 Batch Size 설정을 조정하여 쿼리 수를 37개에서 5개로 줄였습니다.  
또한 Spring AOP를 활용해 주요 요청 흐름에 대한 로깅을 적용하여 디버깅과 추적이 용이하도록 개선했습니다.

<br>

# ✅ Result

### 회원 도메인을 담당하며 인증, 인가, 토큰 관리, 이메일 인증, 소셜 로그인 등 서비스의 핵심 사용자 흐름을 구현했습니다.  
### JWT와 Redis를 활용해 인증 상태를 관리하고, Spring Security 기반의 필터 체인 구조를 적용하며 보안 흐름을 고려한 백엔드 개발 경험을 쌓았습니다.

### 또한 N+1 문제 개선과 AOP 로깅 적용을 통해 기능 구현 이후의 성능과 운영 관점까지 고려하며 프로젝트를 개선했습니다.
